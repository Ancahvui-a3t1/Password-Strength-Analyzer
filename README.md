# 🔐 Password Strength Analyzer

A beginner-friendly Python project that evaluates the strength of user-entered passwords based on basic security criteria.

## 📌 Project Overview

The Password Strength Analyzer is a simple Python application designed to check password strength and provide suggestions to improve password security.

It evaluates passwords based on length, uppercase letters, lowercase letters, numbers, and special characters.

## ✨ Features

- Checks password length (minimum 8 characters).
- Detects uppercase and lowercase letters.
- Checks for numeric digits.
- Identifies special characters.
- Classifies passwords as Weak, Medium, or Strong.
- Provides suggestions to improve password strength.
- Uses hidden password input for privacy.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Modules:** `string`, `getpass`

## 📊 Password Evaluation

| Criteria | Requirement |
|---|---|
| Length | At least 8 characters |
| Uppercase | A-Z |
| Lowercase | a-z |
| Numbers | 0-9 |
| Special Characters | !, @, #, etc. |

### Strength Classification

- **Weak:** 0–2 criteria passed
- **Medium:** 3–4 criteria passed
- **Strong:** All 5 criteria passed
